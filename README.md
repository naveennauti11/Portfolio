# Naveen Nautiyal · Video Editor & Motion Designer Portfolio

High-end, video-first motion graphics and video editor portfolio website for **Naveen Nautiyal**.

- **Live Showcase**: Built with React, Vite, Tailwind CSS, and Framer Motion.
- **Self-Hosted Video Streaming**: Native WebM + WebP poster architecture for instant zero-buffer playback.
- **Continuous Motion Parade**: Forward-moving showcase of 116 curated master cuts across Typography, Commercial, AI Video, and Motion Graphics.
- **Flagship Case Studies**: Deep editorial breakdowns of commercial and client campaigns.
